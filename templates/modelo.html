01 · Modelo Entidad-Relación

Modelo Entidad-Relación

El modelo E-R representa la estructura operacional del negocio agrícola. Identifica 11 entidades con sus relaciones y sirve como base para el diseño del modelo dimensional. La entidad central PRODUCCION conecta las dimensiones de cultivo, variedad, municipio, clima, impacto y economía.

Diagrama Entidad-Relación · AgroClima Colombia 11 entidades · SQL Server
Entidades identificadas: PRODUCCION (central) · REGISTRO_CLIMATICO · FENOMENO_ENSO · CULTIVO · VARIEDAD · CATEGORIA_CULTIVO · MUNICIPIO · DEPARTAMENTO · REGION · PAIS · IMPACTO · ECONOMIA
Relaciones clave: PRODUCCION referencia MUNICIPIO (geografía), VARIEDAD (cultivo), REGISTRO_CLIMATICO (clima), IMPACTO y ECONOMIA.

02 · Modelo Estrella

Esquema Estrella

El modelo estrella desnormaliza el E-R en una tabla de hechos central (FACT_PRODUCCION) conectada directamente a 6 dimensiones. Esta estructura optimiza las consultas analíticas OLAP al eliminar los joins múltiples del modelo operacional.

Diagrama Estrella · Data Warehouse AgroClima · esquema dw 1 FACT · 6 DIM · SQL Server
FACT_PRODUCCION conecta 6 dimensiones: DIM_TIEMPO · DIM_CULTIVO · DIM_GEOGRAFIA · DIM_CLIMA · DIM_IMPACTO · DIM_ECONOMIA.
Granularidad: 1 registro = 1 cultivo × 1 municipio × 1 mes × condición climática específica.
Granularidad del grano
1 registro = 1 cultivo en 1 municipio en 1 mes con condición climática y su impacto económico registrado.
Jerarquías de análisis
Tiempo: Mes → Trimestre → Año
Geo: Municipio → Depto → Región
Cultivo: Variedad → Tipo → Categoría
Métricas calculables
Producción total por región/año
Variación % en año El Niño
Correlación temperatura ↔ rendimiento

05 · Proceso ETL

Extract · Transform · Load

El proceso ETL transforma los 5 datasets fuente (CSV) al modelo estrella del Data Warehouse. Se implementó con Pandas para la extracción y limpieza, y SQL Server para la carga final.

01 · Extract
Extracción
Lectura de 5 CSVs con Pandas. EVA (928 filas) · FAO (272) · Sensores (2.000) · CropYield (1.904) · AgroNET (300). Total: 5.404 registros.
02 · Clean
Limpieza
dropna() en columnas clave · filtros de rango físico (temp, área, producción) · validación de tipos · completitud resultante >99%.
03 · Transform
Transformación
Desnormalización E-R → Estrella · generación de surrogate keys · categorización ENSO · cálculo de rendimiento_t_ha derivado.
04 · Load
Carga DW
INSERT en DIM_* primero (dimensiones) · luego FACT_PRODUCCION con FK resueltas · verificación de integridad referencial.
# ETL — engine.py: Extracción y limpieza con Pandas
def _pd(name):
    df = pd.read_csv(_p(name))          # Extract: leer CSV fuente

    if "produccion" in name:
        df = df.dropna(subset=["Cultivo", "Produccion_t"])  # Clean
        df = df[df["Produccion_t"] > 0]               # Validar rango
        df = df[df["Area_Sembrada_ha"] > 0]

    elif "Sensores" in name:
        df = df.dropna()
        df = df[df["temperatura_c"].between(5, 40)]   # Rango físico
        df = df[df["humedad_suelo_pct"].between(0, 100)]

    _cache[name] = df                          # Cache en memoria
    return df

# Transform: desnormalización → modelo estrella
def eva_produccion_anual():
    df = _pd("EVA_produccion.csv")
    return (df.groupby(["Año", "Cultivo", "Fenomeno_ENSO"])["Produccion_t"]
              .sum().reset_index().sort_values(["Cultivo", "Año"]))
06 · Consultas Analíticas

Consultas sobre el modelo estrella

Las siguientes consultas demuestran el poder analítico del modelo estrella para responder preguntas de negocio que el modelo E-R operacional no podría responder eficientemente.

Q1 · Caída producción café en El Niño
Comparativa ENSO · FACT_PRODUCCION × DIM_TIEMPO × DIM_CULTIVO
SELECT
    t.fenomeno_enso,
    AVG(f.rendimiento_t_ha)  AS rend_prom,
    SUM(f.produccion_ton)    AS prod_total
FROM dw.FACT_PRODUCCION f
    JOIN dw.DIM_TIEMPO  t ON f.id_tiempo  = t.id_tiempo
    JOIN dw.DIM_CULTIVO c ON f.id_cultivo = c.id_cultivo
WHERE c.nombre_cultivo = 'Café'
GROUP BY t.fenomeno_enso
ORDER BY rend_prom DESC;
Resultado: El Niño → 0.59 t/ha · Normal → 0.82 t/ha · La Niña → 0.72 t/ha.
Caída de −28% en rendimiento durante El Niño.
Q2 · Regiones más afectadas históricamente
FACT × DIM_GEOGRAFIA × DIM_IMPACTO
SELECT
    g.region,
    SUM(i.ha_afectadas)       AS ha_total,
    SUM(i.familias_afectadas) AS familias,
    SUM(i.perdidas_cop_mill)  AS perdidas
FROM dw.FACT_PRODUCCION f
    JOIN dw.DIM_GEOGRAFIA g ON f.id_geografia = g.id_geografia
    JOIN dw.DIM_IMPACTO   i ON f.id_impacto   = i.id_impacto
GROUP BY g.region
ORDER BY ha_total DESC;
Resultado: Región Caribe lidera con 38% de ha afectadas.
Seguida por Eje Cafetero (25%) y Llanos Orientales (18%).
Q3 · Correlación temperatura-rendimiento
FACT × DIM_CLIMA · análisis de dispersión
SELECT
    cl.fenomeno_enso,
    ROUND(cl.temperatura_media_c, 0) AS temp_grupo,
    AVG(f.rendimiento_t_ha)          AS rend_prom,
    COUNT(*)                         AS n
FROM dw.FACT_PRODUCCION f
    JOIN dw.DIM_CLIMA cl ON f.id_clima = cl.id_clima
GROUP BY cl.fenomeno_enso,
         ROUND(cl.temperatura_media_c, 0)
ORDER BY temp_grupo;
Resultado: Correlación negativa significativa.
Por encima de 30°C el rendimiento cae un 45% respecto al óptimo (22°C).
Q4 · KPI resumen ejecutivo por año
Vista VW_KPI_RESUMEN · todos los hechos
SELECT
    t.anio,
    t.fenomeno_enso,
    SUM(f.produccion_ton)      AS prod_total,
    AVG(f.rendimiento_t_ha)    AS rend_prom,
    SUM(i.ha_afectadas)        AS ha_afect,
    AVG(cl.temperatura_media_c) AS temp_media
FROM dw.FACT_PRODUCCION f
    JOIN dw.DIM_TIEMPO  t  ON f.id_tiempo    = t.id_tiempo
    JOIN dw.DIM_IMPACTO i  ON f.id_impacto   = i.id_impacto
    JOIN dw.DIM_CLIMA   cl ON f.id_clima      = cl.id_clima
GROUP BY t.anio, t.fenomeno_enso
ORDER BY t.anio;
Resultado: Disponible como vista dw.VW_KPI_RESUMEN en SQL Server. Conectada directamente a Power BI.
07 · Conclusiones

Análisis multidimensional

El modelo estrella permite análisis que el modelo operacional E-R no puede ofrecer eficientemente. Las 6 dimensiones habilitan el análisis desde perspectivas simultáneas que revelan patrones ocultos.

01 · Dimensión Tiempo
La temporalidad revela ciclos de vulnerabilidad
La dimensión DIM_TIEMPO con el atributo fenomeno_enso permite comparar directamente años equivalentes bajo diferentes condiciones climáticas. El análisis multidimensional revela que los episodios El Niño de 2009-2010, 2015-2016 y 2023-2024 siguen un patrón de intensificación progresiva.
02 · Dimensión Clima
El umbral de 30°C es el punto de quiebre
DIM_CLIMA con anomalia_temp_c permite cuantificar exactamente cuánto calor extra genera cada episodio ENSO. El análisis confirma que +1.68°C de anomalía supera el umbral crítico del café (30°C), desencadenando una caída no-lineal del rendimiento.
03 · Dimensión Geografía
La vulnerabilidad no es uniforme en el territorio
DIM_GEOGRAFIA con indice_riesgo y piso_termico permite identificar que la Región Caribe (riesgo 92) es estructuralmente más vulnerable que la Región Andina (riesgo 70), por su dependencia de lluvia y ausencia de infraestructura de riego.
04 · Dimensión Cultivo
El café y la papa concentran el mayor riesgo
DIM_CULTIVO con umbral_temp_max_c y nivel_vulnerabilidad permite segmentar qué cultivos son más sensibles. El análisis multidimensional muestra que café (umbral 30°C) y papa (18°C) son los más vulnerables al cambio climático.
05 · Dimensión Impacto
El déficit hídrico domina el 55% de los daños
DIM_IMPACTO con tipo_dano permite categorizar y cuantificar la naturaleza de cada crisis. El análisis multidimensional revela que el déficit hídrico (sequía por El Niño) genera más hectáreas afectadas que las inundaciones por La Niña.
06 · Dimensión Economía
El precio sube cuando la cosecha cae — ironía cafetera
DIM_ECONOMIA con precio_interno_cop conectado a los años de El Niño en DIM_TIEMPO revela la paradoja: cuando El Niño destruye la cosecha y el precio internacional sube, los caficultores que perdieron su producción no se benefician del alza.
